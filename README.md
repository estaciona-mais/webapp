# webapp
Aplicativo web do projeto Estaciona+.

## Execução
O aplicativo pode ser disponibilizado para uso local com os comandos:
```sh
npm i
npm run dev
```

## Estrutura de arquivos
```
public         # arquivos de mídia
src            # código fonte do projeto
├── components # componentes reutilizáveis
├── contexts   # contextos do React
├── misc       # utilidades auxiliares
├── pages      # arquivos principais para cada rota do aplicativo
├── services   # serviços externos utilizados
└── styles     # folhas de estilos
```
